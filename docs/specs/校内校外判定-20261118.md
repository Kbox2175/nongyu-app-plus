## 3 三个关键设计点

### 3.1 三态而非布尔：Unknown 绝不冒充结论

`CampusNetworkState.Presence` 有 **Unknown / Direct / Vpn** 三个值，不是 `Boolean`。

- `Unknown` → **不挂头、不上报**，后端用自己的默认值
- 把 Unknown 当成 Vpn 会造成「探测失败 = 谎称在校外」，而校外的地址形态需要网关票，
  误判会连带一串失败

后端 `presence.Mode` 只有 `direct`/`vpn` 两个值，所以 **Unknown 只存在于客户端，永不上报**。

### 3.2 探测用的是裸 OkHttpClient，不是农屿的 client

探测打的是**学校域名** `https://jiaowu.sicau.edu.cn/`。复用车屿 client 会：
- 让 `AppSignInterceptor` 给学校域名带 NY1 签名头
- 让 `AuthInterceptor` 带农屿 Bearer

与 `login/data/cas/` 同一隔离原则。所以 `CampusNetworkProbe` 自建一个**无任何拦截器**的 client。

### 3.3 判定口径：任何 HTTP 响应都算可达

```
拿到任何 HTTP 响应（含 3xx/4xx/5xx） → Direct（域名可达 = 在校园网内）
IOException（超时/DNS/连接被拒）       → Vpn（不可达 = 校外）
其它异常                               → Unknown（不冒充）
```

**401/403 也算校内** —— 它说明域名打得通，只是没登录。这是判定「网络可达」而非「有权访问」。

## 6 踩到的坑

- `NongyuGateWay` 加构造参数导致 **4 个既有测试编译失败**（`CancelSemanticsTest` /
  `NongyuGateWayE2ETest` / `LoginApiContractTest` / `SchoolRealBackendTest`）。
  加参数时没考虑到所有测试都直接构造该类。
- `reportPresence()` 收 `RequestBody` 而我传了 `String` —— 需要 `.toRequestBody(...)`。
- `ApiFailure` **没有 `Unknown` 子类**（只有 Network/Timeout/Http/Business/Parse/Cancelled），
  最初想用它表达「presence 未装配」是错的；改为让 `presence` 成为非空必需依赖。
